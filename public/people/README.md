# People photos

Drop circular-friendly (square) headshots here for organizers and speakers,
then set the `src` field in `data/workshop.ts`, e.g.:

```ts
{ name: 'Karim Kassab', affiliation: 'Criteo AI Lab', url: '...', src: '/people/karim-kassab.jpg' }
```

Recommended: square images (e.g. 400x400) in `.jpg` or `.webp`.
Reviewers/Program Committee do not use photos.
